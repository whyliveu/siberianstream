# Сибирский стрим

27 ноября 2026, 17:00 МСК. Страница-приглашение для Ники, Саяна и Антохи Гладкова.

## Cloudflare

Подключить существующий Worker `siberianstream` к этому репозиторию, ветка `main`.
Корень проекта: `/`. Команда сборки: оставить пустой. Команда публикации: `npx wrangler deploy`.
Конфигурация `wrangler.jsonc` публикует каталог `dist` на прежнем адресе Worker.

## Обновления

`dist/index.html` — готовая страница. HTML — около 11,5 КБ: фото и шрифты Manrope лежат в локальных `dist/assets` и `dist/fonts`, загружаются независимо и кешируются. Фото розыгрыша подгружается при прокрутке. Внешние CDN не нужны.
`dist/cover-v3.jpg` — отдельная обложка для Telegram-превью.
`dist/status.json` — состояние эфира. Страница проверяет его каждые 15 секунд.

До начала: `{"state":"waiting","joinUrl":null}`.
При реальном старте: `{"state":"live","joinUrl":"https://meet.google.com/КОД-ВСТРЕЧИ"}`.
После эфира: `{"state":"ended","joinUrl":null}`.
Таймер сам не открывает встречу; для старта изменить статус и опубликовать.

Публичная ссылка донатов: https://www.donationalerts.com/r/mashkasad .
Секретные токены виджетов, ключи и пароли в репозиторий не добавлять.

Manrope распространяется по SIL Open Font License; полный текст в `dist/OFL-Manrope.txt`.

## Автоматическая публикация

После подключения в Cloudflare любой новый коммит в `main` запускает публикацию. ZIP-архивы больше не нужны. После успешного билда проверить фото, кнопку донатов и `/cover-v3.jpg` на живом домене. При неудачном билде оставить предыдущую рабочую версию и изучить журнал сборки; не менять публичную ссылку.
